# Custom Memory Allocator
**No AI generated code was used in the making of the full allocator**

I decided to make this as it would be a good activity to stretch and learn more about how memory allocation on the heap works on a low level.

## The process
I started with the _lite version of the allocator, which uses fixed block sizes, making it very easy to iterate through and allocate/decallocate space as needed. Fragmentation is also much easier to handle in this state. 

I used claude to help explain fundamentals and walk me through making the lite version. At this point the project felt easy ant intuitive. How hard could dynamic allocation be?

Well I've committed myself to the old-fashioned way of learning, its stack overflow and documentation for debugging. Why? I don't know, it feels like more of a learning experience. Is it? Ask me when this is done.

All I've got to go on is the little I learned from the lite version, and that was definetly not enough, though this has gotten me to watch various youtube videos or read articles about all sorts of data concepts, cpp methods, and low level processes related to types in cpp.
